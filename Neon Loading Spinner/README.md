# Neon Loading Spinner

A pure HTML and CSS neon loading spinner. Nested square loaders spin on different axes (`rotate`, `rotateX`, and `rotateY`) with an aqua inset glow against a black background.

## Files

- `index.html` — Page structure and nested loader elements.
- `loading.css` — Flexbox centering, aqua glow styling, and keyframe animations.

## Customization

- Change the `0.5s` animation durations in `loading.css` to adjust the speed.
- Swap `aqua` and `azure` to change the glow and heading colors.
